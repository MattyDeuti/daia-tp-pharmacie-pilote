> premier coup le lendemain.

## Ce que contient une consigne, et ce qu'elle ne contient pas

**L'objectif et les étapes sont à l'écran**, projetés pendant tout le cas pratique. Les fichiers
d'ici ne les répètent pas : ils portent ce qui ne se projette pas.

- **les prompts, en blocs copiables** — un clic vaut mieux qu'une saisie
- **la variante de votre rôle**, là où le TP en prévoit une
- **la preuve attendue** : vous avez fini quand vous pouvez montrer ceci, pas quand vous le sentez
- **quoi faire si ça coince**, avec la sortie de secours
- **le défi bonus**, pour ceux qui finissent tôt

## Si un prompt a changé depuis l'impression de votre mémoire

Les consignes évoluent jusqu'au dernier moment. **Double-cliquez sur « Mettre a jour le TP »**,
sur le Bureau : vous récupérez la dernière version en trois secondes.
